# A simple program written in Python to plug into your calculator and completely ace any 12th grade chemistry exam. 
### (Aimed at my dear professor, *João Cabral*.)


## Origin of the project

During my 12th grade chemistry classes, my professor very innocently allowed us to bring cheat sheets for tests. After my first test, during which I used a very rudimentary python program, I set out to make an executable file for my class' calculator of choice (the Texas Instruments TI-Nspire CX-II T) with a fully-fledged cheat menu complete with atomic radii calculators, atomic history explanations, pair geometry in molecules, and so on. 

## Plans for the project

Each change added to the program will be in accordance to the test dates; for each syllabus published by the professor, a subsequent release adding all the syllabus will be added to the cheat menu, until I've completed 12th grade and all of the syllabus has been added. The program will be subsequently used by all future generations of students of this professor until either calculators that execute python programs are barred or python stops being a language all together. 

## Usage

The python file is included, and is the main file for the project. The actual code is built for fitting inside the tiny calculator screen. Depending on your calculator of choice, you can either directly import the .py file, or translate it to a readable format for your calculator. Due to my class using the popular Texas Instruments TI-Nspire CX-II T, the format it uses (*.ttf*) will be included in every release
